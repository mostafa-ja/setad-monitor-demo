# Setad Tender Monitor — Concept Simulation

**Live demo:** https://mostafa-ja.github.io/setad-monitor-demo/ — the interactive simulation, running in the browser with sample data.

This repository is a **standalone simulation**: a front-end mock-up I built to illustrate the general idea of an intelligent tender-monitoring tool for Iran's Setad platform, using sample data.

**What this is**
- A self-contained front-end simulation with sample data
- An illustration of a concept and an interface direction — nothing more

**What this is not**
- It is not a production system, and it is not a sample, port, or derivative of one
- It contains no production code, architecture, data, or methods, and it is not connected to any live system

My production work in this area — including TenderYar, which makes large tender document packages understandable through summaries and question-answering — is closed and proprietary, and is deliberately not represented here beyond the general concept.
