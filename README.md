# Setad Tender Monitor — Public Demo (Early Sample)

This repository is a small, early sample of my tender-monitoring work for Iran's Setad platform: a front-end demonstration with sample data that sketches the idea and the interface direction.

**What this is**
- A simplified demo interface, built early in the project to explore the concept
- A static front-end only, running on sample data

**What this is not**
- It is not the production system, and it does not contain the production system's code, architecture, or methods
- The real system grew far beyond this sketch and remains closed and proprietary

This line of work later developed into TenderYar, my current (also closed) project: making large tender document packages understandable — clear summaries and answers instead of hundreds of pages.
